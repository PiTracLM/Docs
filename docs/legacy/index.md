# Legacy (V1 / V2)

This section preserves documentation for older PiTrac hardware so that builders who already have a V1 or V2 system can still find what they need. New builds should follow the current [Hardware](../hardware/index.md) and [Software](../software/index.md) guides for the V3 enclosure and Connector Board.

If you have older hardware, it still works. These pages cover the pieces that differ from the current V3 build.
