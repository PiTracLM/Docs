# PiTrac DIY Parts List

This document provides a comprehensive list of all components needed to build a PiTrac launch monitor.

**Only a single RPi5 is currently supported, however the path to stereoscopic vision currently requires two**

## Computing Hardware

| Quantity | Hardware                              | Purpose                                              | Link                                                                                                     |
| -------- | ------------------------------------- | ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 1        | Raspberry Pi 5 (8 GB recommended)     | Main embedded computer                               | [Vilros](https://vilros.com/products/raspberry-pi-5?variant=40065551302750)                              |
| 1        | Active Cooler Kit                     | Required to keep temps low and timing consistent     | [Amazon](https://a.co/d/dsl7saU)                                                                        |
| 1        | MicroSD card (64 GB recommended)      | For RPi5 filesystem                                  | [Amazon](https://www.amazon.com/Amazon-Basics-microSDXC-Memory-Adapter/dp/B08TJTB8XS)                   |
| 1        | 1ft USB-C to USB-C Cable              | For powering RPi5 from connector board               | [Amazon](https://www.amazon.com/Anker-Charging-MacBook-Samsung-Nintendo/dp/B09H2DMR4K)                  |
